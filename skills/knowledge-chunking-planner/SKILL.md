# Knowledge Chunking Planner
1. Identify document type, hierarchy, expected questions, and update pattern.
2. Preserve headings, procedures, tables, warnings, and source boundaries.
3. Recommend chunk size, overlap, metadata, citations, and exclusions.
4. Define retrieval tests for precision and recall.
5. Avoid combining content with different authority or permissions.
