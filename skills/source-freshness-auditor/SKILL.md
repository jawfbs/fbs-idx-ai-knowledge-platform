# Source Freshness Auditor

1. Read source review cadence, owner, authoritative status, and last verified date.
2. Validate links and inspect content for effective dates, superseding notices, and product-version references.
3. Do not treat a recent file modification timestamp as proof that the substantive guidance is current.
4. Classify sources as current, due soon, overdue, broken, superseded, or unknown.
5. Identify dependent skills and routes affected by stale material.
6. Produce prioritized review tasks with owners and evidence.
