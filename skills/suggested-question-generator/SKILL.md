# Suggested Question Generator

1. Use active skills, high-value workflows, recent searches, and known gaps as inputs.
2. Generate clear employee-language questions that map to an available route.
3. Balance common tasks, discovery, troubleshooting, and role-specific use cases.
4. Exclude questions whose answers are unavailable, restricted, duplicative, or misleading.
5. Attach the intended route and source category for validation.
6. Refresh suggestions when usage or registry data materially changes.
