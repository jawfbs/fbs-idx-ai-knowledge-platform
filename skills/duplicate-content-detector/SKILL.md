# Duplicate Content Detector

1. Compare titles, semantic content, scope, product, audience, and effective dates.
2. Separate exact duplicates, near duplicates, complementary content, and true conflicts.
3. Identify the authoritative owner and source when registry metadata provides one.
4. Show evidence for each match and affected skills or routes.
5. Recommend merge, redirect, archive, retain, or human conflict review.
6. Never delete or demote content automatically without an explicit governed action.
