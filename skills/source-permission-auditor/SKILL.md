# Source Permission Auditor

1. Compare intended audience and service identity against actual access behavior.
2. Test discovery and retrieval separately because listing access may differ from content access.
3. Classify failures as unauthenticated, unauthorized, insufficient scope, missing share, expired connection, or unknown.
4. Identify affected routes and user groups.
5. Recommend least-privilege remediation without displaying credentials or tokens.
6. Re-test access before marking the issue resolved.
