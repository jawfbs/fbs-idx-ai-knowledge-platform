# Flexmls Search Builder
1. Normalize criteria into location, property type, status, price, features, dates, and exclusions.
2. Resolve available fields through Flexmls metadata when needed.
3. Explain unavailable or conflicting filters.
4. Provide ordered search steps and save or subscription guidance.
5. Do not invent field names or local availability.
