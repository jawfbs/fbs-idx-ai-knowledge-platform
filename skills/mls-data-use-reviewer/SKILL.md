# MLS Data Use Reviewer
1. Define the data, source MLS, users, purpose, product, storage, and distribution.
2. Retrieve current governing rules and agreements.
3. Identify permitted, prohibited, conditional, and uncertain uses.
4. Return risks, required controls, approvals, and sources.
5. Require compliance review for unresolved interpretations.
