# Google Sheets Ops Reporter
1. Confirm the sheet, tabs, date range, metric definitions, and audience.
2. Validate formulas, missing values, duplicates, and date consistency.
3. Summarize trends, exceptions, and operational impact.
4. Return a concise report with source ranges and action owners.
5. Do not silently repair source data.
