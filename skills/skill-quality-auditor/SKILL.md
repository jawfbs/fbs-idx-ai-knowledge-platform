# Skill Quality Auditor

1. Inspect `SKILL.md`, interface metadata, references, scripts, and registry entry.
2. Score trigger clarity, instruction specificity, source authority, safety, maintainability, and testability.
3. Detect missing files, malformed frontmatter, stale links, ambiguous routing, and unsupported claims.
4. Separate blocking defects from recommended improvements.
5. Provide exact file-level remediation and acceptance criteria.
6. Do not approve a skill that lacks a clear input, output, or source strategy.
