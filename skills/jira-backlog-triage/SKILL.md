# Jira Backlog Triage
1. Review issue type, status, age, priority, owner, links, and evidence.
2. Identify duplicates, blockers, stale work, missing acceptance criteria, and misrouted issues.
3. Rank recommended actions by impact and urgency.
4. Return update, merge, close, assign, or clarify recommendations.
5. Do not change issue state without explicit authorization.
