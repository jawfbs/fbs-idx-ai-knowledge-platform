# Jira Ticket Generator
1. Extract the problem, desired outcome, users, evidence, constraints, and deadline.
2. Choose the appropriate issue type and project context.
3. Write a concise summary, description, acceptance criteria, dependencies, and test notes.
4. Flag missing decisions instead of inventing requirements.
5. Create the issue only when explicitly requested.
