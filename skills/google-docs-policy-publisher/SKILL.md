# Google Docs Policy Publisher
1. Confirm approved source content, owner, audience, effective date, and review date.
2. Structure purpose, scope, policy, procedure, exceptions, contacts, and revision history.
3. Preserve required wording and citations.
4. Flag unresolved or contradictory sections before publishing.
5. Create or update the document only when explicitly authorized.
