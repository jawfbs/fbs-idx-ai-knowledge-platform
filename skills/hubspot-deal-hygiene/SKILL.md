# HubSpot Deal Hygiene
1. Review open deals and required properties using current CRM definitions.
2. Flag missing, contradictory, stale, or duplicate data.
3. Prioritize records by pipeline impact and age.
4. Recommend exact property updates and responsible owner.
5. Apply changes only when explicitly requested and supported.
