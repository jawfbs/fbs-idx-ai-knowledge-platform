# IDX Requirements Verifier

1. Identify the exact MLS, product, website or display type, and requested requirement.
2. Search the registered authoritative MLS or FBS requirement source first.
3. Record the source date, scope, and any conflicting guidance.
4. Separate confirmed requirements from interpretations and unresolved exceptions.
5. Return the requirement, implementation impact, source link, and required human review.
6. Never generalize one MLS rule to another MLS.
