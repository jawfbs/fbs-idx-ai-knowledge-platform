# Flexmls Account Access Helper
1. Capture user role, organization, error, affected environment, and recent changes.
2. Search current Flexmls Help before recommending steps.
3. Distinguish credential, permission, office, browser, and service issues.
4. Return safe troubleshooting steps and escalation criteria.
5. Never request or expose passwords or secret tokens.
