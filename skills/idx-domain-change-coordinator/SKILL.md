# IDX Domain Change Coordinator
1. Capture current domain, new domain, product, account, MLS, target date, and DNS owner.
2. Identify configuration, authorization, tracking, and redirect impacts.
3. Build a sequenced change and validation checklist.
4. Include rollback steps and customer communication.
5. Escalate unresolved DNS, certificate, or MLS restrictions.
