# Flexmls Help Router

1. Classify the request as how-to, setting location, subscription, permission, or troubleshooting.
2. Use the registered Flexmls MCP help action rather than static internal documentation when available.
3. Return a direct answer, numbered steps when required, authoritative source links, and relevant follow-up questions.
4. State any account role, MLS configuration, or product-version dependency that could change the answer.
5. Do not invent menu labels, permissions, or error causes. If the MCP source does not resolve the question, mark the answer for escalation and list the missing details.
6. Offer a support-response-ready version when the user needs customer-facing language.
