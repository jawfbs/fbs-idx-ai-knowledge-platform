# IDX Support Response

1. Use only verified facts from the supplied context and authoritative sources.
2. Lead with the direct answer or current status.
3. Provide numbered steps when the customer must take action.
4. Separate customer actions from internal support actions.
5. Include source links when available.
6. State uncertainty, missing access, or escalation needs explicitly.
7. Keep the default response concise, professional, and ready to paste into a ticket or email.
8. Never expose internal-only notes, credentials, private links, or implementation details.
