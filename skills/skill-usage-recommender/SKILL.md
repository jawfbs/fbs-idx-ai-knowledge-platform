# Skill Usage Recommender

1. Group repeated tasks and questions by intent, inputs, outputs, source needs, and user role.
2. Exclude one-off requests and problems better solved by documentation or connector repair.
3. Estimate frequency, time saved, risk, source readiness, and overlap with existing skills.
4. Recommend create, extend, merge, or do not automate.
5. Produce a proposed name, trigger description, workflow, connectors, tests, and priority.
6. Flag skills requiring policy or subject-matter review before implementation.
