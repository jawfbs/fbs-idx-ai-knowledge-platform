# Automation Failure Triage
1. Capture workflow, run ID, timestamps, environment, trigger, and error evidence.
2. Locate the failure stage and affected records.
3. Check authentication, permissions, schema changes, limits, and retries.
4. Return root-cause confidence, safe recovery, and prevention steps.
5. Avoid replaying writes that could create duplicates without safeguards.
