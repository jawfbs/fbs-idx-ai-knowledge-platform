# IDX Display Compliance Checker
1. Identify MLS, product, page type, and implementation URL.
2. Retrieve current authoritative rules before evaluating the display.
3. Check attribution, disclaimers, prohibited fields, refresh behavior, branding, and links.
4. Return compliant, noncompliant, and uncertain findings with sources.
5. Require human review for ambiguous or changing MLS rules.
