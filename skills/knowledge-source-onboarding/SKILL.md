# Knowledge Source Onboarding

1. Identify source type, scope, owner, audience, authority, permissions, and review cadence.
2. Validate the connector and run representative discovery and retrieval tests.
3. Define allowed content, exclusions, route tags, fallback priority, and failure behavior.
4. Record authentication requirements without storing secrets in repository files.
5. Add the source registry entry and create verification questions.
6. Mark the source active only after access, quality, and result-format tests pass.
