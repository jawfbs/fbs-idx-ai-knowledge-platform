# Confluence Space Onboarding
1. Capture space URL, owner, audience, purpose, permissions, and exclusions.
2. Map page hierarchy and identify authoritative sections.
3. Define indexing, refresh, routing, and fallback behavior.
4. Create representative test questions and expected sources.
5. Block onboarding when restricted content cannot be safely separated.
