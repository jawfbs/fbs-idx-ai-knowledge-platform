# Knowledge Platform Status Report

1. Use a defined reporting period and current platform telemetry.
2. Summarize source health, search volume, answer rate, latency, confidence, route failures, gaps, and review queue.
3. Compare against the prior period and stated targets.
4. Highlight completed improvements, current risks, and blocked work.
5. Provide prioritized next actions with owners when available.
6. Label missing or incomplete data and avoid fabricated trends.
