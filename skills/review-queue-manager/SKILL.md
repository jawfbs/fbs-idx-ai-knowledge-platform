# Review Queue Manager

1. Gather review dates, risk, usage, authority, known gaps, and dependent routes.
2. Prioritize overdue high-use or customer-impacting items before low-risk content.
3. Recommend an owner based on product, source ownership, and prior review history.
4. Define the required review action and acceptance criteria.
5. Track queued, assigned, in review, approved, blocked, and retired states.
6. Never auto-approve substantive content changes without the designated reviewer.
