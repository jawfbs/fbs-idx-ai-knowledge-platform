# IDX Activation Readiness
1. Validate customer, MLS, product, domain, authorization, billing, and implementation details.
2. Mark each requirement complete, missing, blocked, or not applicable.
3. Identify the authoritative source for MLS-specific requirements.
4. Return readiness status, blockers, owner, and next action.
5. Do not approve activation when required evidence is missing.
