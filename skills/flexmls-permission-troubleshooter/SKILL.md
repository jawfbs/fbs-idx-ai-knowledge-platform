# Flexmls Permission Troubleshooter

1. Identify the blocked action, user role, office relationship, listing ownership, and MLS.
2. Check current Flexmls Help and available account context for required permissions.
3. Separate product permissions, MLS restrictions, listing-level conditions, and browser or session issues.
4. Provide verification steps before recommending administrative changes.
5. State who can authorize or perform the change when the user cannot.
6. Escalate with exact evidence when the documented permissions appear correct.
