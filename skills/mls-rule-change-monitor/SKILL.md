# MLS Rule Change Monitor
1. Compare the new authoritative rule with the prior approved version.
2. Extract effective date, scope, obligations, exceptions, and source.
3. Identify affected products, customers, documentation, skills, and owners.
4. Return required actions and deadlines.
5. Mark uncertain interpretations for compliance review.
