# Search Analytics Reporter

1. Use the configured analytics source and requested date range.
2. Report volume, answer rate, median latency, confidence distribution, route usage, and top unanswered topics.
3. Separate content gaps, routing failures, connector failures, and permission failures.
4. Compare with the prior equivalent period when data is available.
5. Highlight material changes and recommend prioritized corrective actions.
6. Do not infer user intent or performance from incomplete telemetry without labeling the limitation.
