# Answer Quality Validator

1. Map each material claim to an authoritative source or mark it unsupported.
2. Check source freshness, scope, permissions, and conflicts.
3. Verify that instructions are complete, ordered, and appropriate for the user's role.
4. Flag overconfident wording, invented details, missing caveats, and internal-only disclosures.
5. Return pass, revise, or block with concise reasons and corrected wording where possible.
6. Require human review for customer-facing compliance, pricing, authorization, or MLS-specific claims.
