# Spark API Error Troubleshooter
1. Capture endpoint, method, status, response body, environment, and sanitized request details.
2. Classify authentication, authorization, validation, rate limit, dataset, or service failure.
3. Compare the request to current documentation.
4. Return likely cause, safe tests, correction, and escalation package.
5. Remove secrets from all output.
