# Confluence Page Curator
1. Review page purpose, owner, hierarchy, labels, links, and last meaningful review.
2. Compare with related pages and authoritative sources.
3. Flag duplicate, stale, contradictory, orphaned, or restricted content.
4. Recommend edits, archive, merge, or approval actions.
5. Preserve page history and source attribution.
