# Spark API Access Reviewer
1. Capture organization, developer, use case, MLS, datasets, environment, and requested scopes.
2. Verify eligibility and authorization from approved sources.
3. Identify missing approvals, credentials, agreements, or technical prerequisites.
4. Return readiness status and next steps.
5. Never expose credentials or approve restricted access without evidence.
